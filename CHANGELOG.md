# Changelog

## 0.0.1 — 2026-10-27

Initial Capacitor 8 integration for Microsoft Clarity:

- Typed API for initialization, identity, tags, events, screen names and consent.
- Android native sessions, recording URLs, pause/resume and retained session events.
- Experimental iOS bridge with Swift Package Manager and CocoaPods declarations.
- Web integration with the Microsoft Clarity tag; native-only APIs reject explicitly.
- Interactive example app with generated Android and iOS projects.

Android capture and successful uploads were verified on an API 36 emulator.
iOS compilation and replay remain unverified.
